全繁體中文的**線上影片剪輯工具**，打開瀏覽器就能剪片。所有影片、音樂、圖片都只在你的瀏覽器裡處理，**不會上傳到任何伺服器**。

設計參考開源剪輯軟體 [FilmCraft](https://github.com/storytold/filmcraft)（純 Rust 打造、對標 Adobe Premiere Pro）的概念，用純 HTML / JavaScript 重新實作成單一網頁。

## 使用方式

可以在手機瀏覽器選「加入主畫面」，就會出現小柯圖示，像 App 一樣全螢幕開啟。

直接用瀏覽器（建議 Chrome / Edge）開啟 `index.html`，或啟用 GitHub Pages 後從網址開啟。

快捷鍵：`空白鍵` 播放／暫停、`S` 分割、`Delete` 刪除、`Shift+Delete` 波紋刪除、`D` 複製、`T` 加字幕、`← →` 逐格移動、`Ctrl+Z` 復原。

## 程式設計（領域模型）

參考 FilmCraft 的架構概念：

- **精確時間**：所有剪輯運算用整數 tick（每秒 254,016,000,000，可被常見影格率整除），不用浮點秒數，剪再久也不會飄。
- **一切皆指令**：按鈕、快捷鍵、小柯助手都呼叫同一套指令（例如 `timeline.split`、`color.set`、`text.add`），每個指令有 id、參數，可復原。
- **領域物件**：媒體（Media）→ 片段（Clip）→ 軌道（Track）→ 序列（Sequence）。比喻：Media 是倉庫裡的原始膠卷，Clip 是剪下來貼到剪輯桌上的一小段，Track 是桌上一條條軌道。

## 限制

- 匯出是把整支影片即時播放一遍並錄下來，片長多久就需要多久，匯出時請讓分頁保持在前景。
- 大型或特殊編碼的影片取決於瀏覽器的解碼能力。
