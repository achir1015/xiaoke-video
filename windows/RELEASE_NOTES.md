## 下載安裝

1. 下載下方的 **XiaokeVideo-Setup-版本.exe**
2. 執行後按「下一步」，安裝位置可以改成 `E:\小柯影音剪輯助手`
3. 完成後從開始功能表或桌面捷徑開啟

> 第一次執行時，Windows SmartScreen 可能提示「Windows 已保護您的電腦」，因為安裝檔沒有付費的程式碼簽章。請按「其他資訊」→「仍要執行」。

此版本已在 GitHub 的 Windows 雲端電腦上自動完成：建置 → 靜默安裝 → 開啟 App 自我測試（剪輯指令、匯出影片、存檔）→ 解除安裝。`selftest-report.json` 是測試報告，`selftest-editor.png` 是測試時的畫面截圖。
