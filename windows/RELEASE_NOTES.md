## 下載安裝

### Windows 11
1. 下載下方的 **XiaokeVideo-Setup-版本.exe**
2. 執行後按「下一步」，安裝位置可以改成 `E:\小柯影音剪輯助手`
3. 完成後從開始功能表或桌面捷徑開啟

> 第一次執行時，Windows SmartScreen 可能提示「Windows 已保護您的電腦」，因為安裝檔沒有付費的程式碼簽章。請按「其他資訊」→「仍要執行」。

### Mac（MacBook Pro／Air、iMac、Mac mini）
1. 依晶片下載：Apple M 系列晶片選 **XiaokeVideo-mac-AppleSilicon-版本.dmg**，Intel 處理器選 **XiaokeVideo-mac-Intel-版本.dmg**（蘋果選單 →「關於這台 Mac」可以看晶片）
2. 打開 .dmg，把「小柯影音剪輯助手」拖到「應用程式」
3. 第一次開啟：在「應用程式」裡對 App 按右鍵 →「打開」；若沒有「打開」可按，到「系統設定 → 隱私權與安全性」按「強制打開」

### iPad／iPad Pro
1. 用 iPad 的 Safari 開啟 https://achir1015.github.io/xiaoke-video/
2. 按分享按鈕 →「加入主畫面」，桌面就會出現「小柯剪輯」圖示，像 App 一樣全螢幕開啟，沒網路也能用
3. 建議橫放使用；匯出的影片會存到「檔案」App 的「下載項目」

此版本已在 GitHub 的雲端電腦上自動完成：Windows 建置 → 靜默安裝 → 開啟 App 自我測試（剪輯指令、匯出影片、存檔）→ 解除安裝；Mac 建置 → 開啟 App 自我測試 → 打包 .dmg。`selftest-report.json` 是 Windows 測試報告，`selftest-editor.png` 是測試時的畫面截圖。
